# Wisp & Co. 🌿

A phone-first Android live wallpaper and companion app about an independent, evolving little spirit living in a whimsical storybook world.

## Goals
- An animated **live wallpaper** with visible, location-specific weather that also changes Wisp's behaviour.
- An explorable world with a **cottage interior**, pond, forest, garden, bees, dragonflies, and woodland inhabitants.
- Independent projects, discoveries, memory, emotional moments, and interactions without neglect penalties.
- A personality-matching introduction with meaningful spirit forms (antlers, moth wings, plant sprout, woodland forms) and reversible appearance evolution.
- Optional seasonal and cultural activities, including carving pumpkins, Christmas tree decorating, and respectful Hanukkah celebrations.
- A soft, less-busy illustrated aesthetic.
- Future Pixel Watch 2 support, with one shared creature and world.

## Status
Repository initialization. Native Android source and artwork are still being integrated. **No working APK has been built or device-tested yet.**

## Privacy
No personal addresses, live GPS readings, secrets, access tokens, or private user data should be committed here. Weather location is optional and should be processed on-device.
